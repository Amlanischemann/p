# Pharmed UG | Men’s Health & Vitality website section

**Ready to preview:** open `mens-health.html` in a browser. Works as a standalone page, including when opened as a local file.

**Add to existing website:** upload `mens-health.html` and the whole `assets` folder to the same GitHub Pages repository directory as `index.html`. Add `<a href="mens-health.html">Men’s Health</a>` to the main website navigation. Existing `index.html` is intentionally not replaced. Main-website links on the add-on go to `index.html`.

Features: premium mobile-responsive collection design; six product/category tiles; search, filters, bottle-style HTML/CSS visualizations; full expandable ingredient tables; mechanisms and claim candidates; commercial export section.

**Important:** These are proposed formulas and mockup labels for B2B development. Not a finished SKU, approved product label, efficacy claim or authorization to sell. Obtain formula, dose, ingredient and claim clearance for each destination market before publication as purchasable products.

The PDF print catalogue has deliberately not been prepared yet, per client instruction.
