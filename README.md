# Pharmed UG trilingual website draft

Languages: German, English and Arabic (RTL).

Open `index.html` to preview locally. Upload **all contents of this directory**, including `assets/`, to the root of the GitHub repository `Amlanischemann/p`. Enable GitHub Pages from `main` / `(root)`.

Product images are user-supplied concept illustrations and PDF-derived pages, **not verified packaging or sale-ready labels**. The original illustrations contain potential unsupported health claims and “Made in Germany” statements. They must be replaced with legally reviewed imagery before commercial publication. The site displays prominent concept disclaimers and conservative product descriptions. Confirm actual formulas, pack sizes, manufacturing country, regulatory status, German/EU health claims and allergen information before launch. Eye/nasal drops and animal products require separate regulatory assessment.

Complete the Impressum, privacy notice, contact information, company status, and legal review before publishing publicly. This is a review draft; GitHub Pages is not intended for commercial e-commerce hosting.
